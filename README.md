# Corporate Finance (AI Plus One)

**Draft excerpt.** This initial chapter is not the complete textbook and does not replace an existing edition.

An MBA-level book about financial decisions from inside a firm. The reader is expected to know basic financial statements and the time value of money. The recurring job is to recommend a choice, document what makes it feasible, and say what would change the recommendation.

[Read the draft chapter: A Good Investment the Firm Cannot Yet Make](chapters/a-good-investment-the-firm-cannot-yet-make.md)

The chapter uses a fictional distributor and a small, original cash-flow dataset. It requires no AI service. A calculator is enough for the exercise; [the reproducible check](scripts/verify_case.py) uses Python 3's standard library. This is teaching material, not individualized financial advice.
